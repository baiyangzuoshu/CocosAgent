# learn_3.8cocoscreator 课程大纲

## 课程目标

以 `engine/3.8.7engine/` 为源码依据，用 TypeScript 逐步实现 Creator 3.8.7 的精简 Web 浏览器运行时。保留模块边界、职责和关键调用顺序，只裁掉当前课程无关的引擎功能。

## 实现约定

- 每课代码放入独立的 `sNN_主题/` 目录，内部路径尽量镜像源码职责。
- 每课是一份完整、可单独运行的代码快照；后一课在前一课基础上增加功能。
- 课程实现用于学习架构，不以兼容完整 Creator 引擎为目标；简化点在课内列出。
- 首轮聚焦浏览器运行时，不接入编辑器场景、原生平台或小游戏平台。

## 每课格式

1. 本课要理解的问题。
2. 3.8.7 源码文件和关键函数位置。
3. 本课新增的独立代码。
4. 一个可观察结果。
5. 必要的简化说明。

## 第一阶段：入口、模块与帧循环

| 课 | 增量内容 | 3.8.7 源码对照 | 阶段结果 |
| --- | --- | --- | --- |
| 0 | 建立浏览器宿主和 TypeScript 入口 | `templates/web-desktop/index.js.ejs`、`templates/launcher/application.ejs` | 页面运行课程入口 |
| 1 | 通过 `exports/base.ts` 导出模块，并建立 `cclegacy` 兼容对象 | `exports/base.ts`、`predefine.ts`、`cocos/core/global-exports.ts`、`cocos/game/index.ts` | 从模块入口取得 `game` 和 `director` |
| 2 | 通过 Promise 链按阶段初始化 Game | `cocos/game/game.ts`：`init`、`EVENT_*_INIT` | 观察 Base、Infrastructure、Subsystem、Project 顺序 |
| 3 | 用 Pacer 驱动 Game 更新回调，再调用 Director | `pal/pacer/pacer-web.ts`：`start`、`_stTime`；`cocos/game/game.ts`：`run`、`_updateCallback`；`cocos/game/director.ts`：`init`、`tick` | 页面帧数持续增加 |
