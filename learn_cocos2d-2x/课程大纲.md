# Cocos2d-x 2.x 源码学习大纲

## 实现约定

- 每课保存一份完整代码快照，可单独编译运行。
- `src/` 按该代源码目录分层；保留本代 API 名称。
- 每课只增加一个主要概念，并在 README 标出本地源码位置与简化范围。
