# learn_langgraph 课程大纲

## 课程目标

以本地 LangGraph Python 1.2.22 快照为依据，沿着公开图 API 追到运行时实现，理解状态如何变成 channel、节点如何被调度，以及执行如何流式输出、保存和恢复。

课程使用逐课递增的精简 Python 实现。它帮助观察调用关系和状态变化，不替代 LangGraph，也不承诺与上游 API 兼容。

## 版本与源码范围

- 版本依据：[AI/langgraph-main/libs/langgraph/pyproject.toml](../AI/langgraph-main/libs/langgraph/pyproject.toml)。
- 核心源码：[AI/langgraph-main/libs/langgraph/langgraph](../AI/langgraph-main/libs/langgraph/langgraph/)。
- 检查点接口与实现：[AI/langgraph-main/libs/checkpoint](../AI/langgraph-main/libs/checkpoint/)。
- 版本、Python 兼容范围及源码职责均以本地快照为准；不把结论外推到其他 LangGraph 版本。

## 每课格式

1. 本课要回答的一个问题。
2. 对应的上游源码文件和关键职责。
3. 本课相对前一课增加的最小 Python 实现。
4. 可观察的运行结果。
5. 简化点和与上游实现的边界。
