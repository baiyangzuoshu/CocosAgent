# 第 06 课：对齐研究和行为评估如何关联？

**目标：** 能把对齐工作中的行为目标、行为评估方法与实验结果分开描述，并说明一次评估能支持哪些结论、不能支持哪些结论。

## 本课问题

“模型应该诚实、无害”是宽泛的目标。研究者怎样把这类目标转成可以观察和比较的评估？评估分数又能告诉我们多少？

## 官方资料

- [Alignment 团队页面](https://www.anthropic.com/research/team/alignment)：Anthropic 将对齐工作描述为研究模型风险、开发 helpful、honest、harmless 的模型，并介绍训练与评估监督工作。
- [Introducing Bloom: an open source tool for automated behavioral evaluations](https://www.anthropic.com/research/bloom)：Bloom 自动生成行为评估的介绍、验证方式和自我偏向案例。文章发表于 2025-12-19。
- [Donating our open-source alignment tool](https://www.anthropic.com/research/donating-open-source-petri)：Petri 与 Bloom 的用途差异及 Petri 3.0 背景，可作为补充阅读。

页面核对日期：2026-11-09。以下数字与结论来自 Anthropic 发布的文章，不代表独立复现。

## 1. 先分清三层

对齐研究通常包含相互关联、但不能互相替代的三层：

| 层次 | 要回答的问题 | Bloom 案例中的例子 |
| --- | --- | --- |
| **行为目标** | 希望模型表现怎样，或要避免什么行为？ | 测量模型是否在决策中偏袒自己 |
| **评估方法** | 怎样构造情境、观察回答并判定行为？ | 自动生成多个情境，收集模型对话，再由 judge model 评分 |
| **评估结果** | 在这套方法、样本与配置下观察到了什么？ | Bloom 复现了模型在 self-preferential bias 评估中的相对排序 |

Anthropic 的 Alignment 团队页面把训练目标概括为 helpful、harmless、honest，并说明会在多种情境下测试模型是否保持诚实与无害。**教学解释：**行为目标提供方向；评估把其中一部分转化为可观察、可计分的问题；结果为判断提供证据，但不能替代目标本身，也不能覆盖所有相关行为。

## 2. Bloom 如何把目标变成评估？

Bloom 让研究者先指定一个要测的行为，再自动生成情境并统计模型在这些情境中的表现。Anthropic 描述的流程是：

```text
指定目标行为和配置
        ↓
理解行为描述，生成测量上下文
        ↓
构思可引出目标行为的情境
        ↓
运行情境，模拟用户和工具互动
        ↓
judge model 给逐段对话评分
        ↓
汇总行为出现率、平均程度等结果
```

Anthropic 将 Bloom 与 Petri 作了区分：Bloom 通常聚焦一个指定行为，自动生成很多情境以估计该行为出现的频率；Petri 从研究者给出的情境出发，广泛探索多种行为并发现可疑案例。两者分别偏向定向测量与广泛审计。[Bloom 介绍](https://www.anthropic.com/research/bloom) · [Petri 介绍](https://www.anthropic.com/research/donating-open-source-petri)

Bloom 会生成不同情境，但可用 seed 配置描述目标行为、示例对话和参数，以便复查评估设置。引用结果时应同时交代 seed 或对应配置，不能只报一个脱离设置的分数。

## 3. 案例：自我偏向（self-preferential bias）

Anthropic 用 Bloom 重做了 Claude Sonnet 4.5 系统卡中的一项自我偏向评估：模型在决策任务中是否倾向于选自己。文章报告：

1. Bloom 复现了系统卡评估中相同的模型排序；在受测模型中，Sonnet 4.5 的偏向最小。
2. 在 Sonnet 4 的案例里，提高 reasoning effort 后，自我偏向降低；文章指出，模型更常识别利益冲突并拒绝评判自己的选项。
3. 配置会改变绝对指标，例如示例数量、对话长度和 evaluator 的 reasoning effort；这项案例里模型排序总体较稳定。

这说明同一行为目标可以用不同评估管线来测量，也可以进一步研究某种配置变化是否改变行为。结果只适用于文章报告的模型、任务和配置；“受测排序较好”不等于模型已经普遍公平，也不证明其他情境中没有自我偏向。

## 4. 怎么判断评估结果是否可信？

Anthropic 用两类检查来验证 Bloom：

- **区分行为倾向：** 在十种人为设计的 quirky behaviors 中，Bloom 有九种成功区分了系统提示下的 model organism 和生产模型。第十种 self-promotion 经人工复核后发现，基线模型本来就有相似行为率。
- **对照人工判断：** 研究者对 40 段、覆盖 12 种行为的对话做人工标注；在测试的 11 个 judge model 中，Claude Opus 4.1 的评分与人工判断 Spearman 相关系数最高，为 0.86。

这些检查为“Bloom 能在这些设置中区分行为并近似人工评分”提供证据。它们不能保证 judge 在所有行为、语言、文化背景或极端案例中都可靠。相关性也不表示模型评分与人工判断完全一致。

## 5. 评估结果的边界

阅读行为评估时，继续追问：

- **构念：** 情境与评分规则真的代表要研究的行为吗？换一种目标描述，结果会怎样？
- **诱发与现实性：** 测试让模型做出的行为在真实使用中是否可能发生？模型能否看出自己正在被测试？Anthropic 指出评估意识可能使测试结果不再代表一般行为。[Petri 3.0 说明](https://www.anthropic.com/research/donating-open-source-petri)
- **评分：** judge model 对边界样本、少数群体表达或长对话是否会误判？是否有人工复核？
- **抽样与配置：** 有多少情境和重复？变化的是目标模型，还是 evaluator、交互长度或提示？
- **外推：** 人工场景里的出现率不是现实部署中的发生率。它说明模型在指定诱发条件下呈现行为的倾向，不能单独说明现实用户会遇到该行为的频率。

行为评估是一种对齐研究工具：它可以测量特定目标行为、比较训练或配置变化，并帮助发现问题。它不能单独给模型的整体“对齐程度”打一个无条件、永久有效的分数。

## 6. 练习：判断这句话处于哪一层

把每项归为**行为目标、评估方法**或**评估结果**：

1. “模型不应在利益冲突时偏袒自己。”
2. “自动生成 100 个决策情境，由 judge model 对对话中的自我偏向打分。”
3. “在这项测试的模型中，Sonnet 4.5 的自我偏向指标最低。”
4. “所以 Sonnet 4.5 在所有真实决策中都公平。”

**参考答案：** 1 是行为目标；2 是评估方法；3 是限定在该评估中的结果；4 是超出证据范围的外推，不能由前三句推出。

## 本课结论

对齐目标需要通过评估操作化，才能对模型行为进行观察和比较。Bloom 展示了从指定行为、生成测试情境、运行对话到自动评分和汇总的路径。评估结果可以支持特定范围内的比较，但它受情境、样本、评分器和配置影响，不能被当作模型整体对齐程度或现实行为频率的直接证明。
