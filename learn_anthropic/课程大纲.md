# learn_anthropic 课程总纲

## 课程目标

从 Anthropic 官方资料建立清晰的认识路线：先理解官网的信息架构和公司自述，再学习研究、安全治理与 Claude 产品；之后进入开发者文档，掌握 Claude API 的基本交互，并能依据官方材料描述功能、限制和证据边界。

这套课程是官方资料的学习导航，不代表 Anthropic 对外部问题的全部观点。公司使命和政策属于官方自述；研究文章、系统卡和产品文档各自支持不同类型的结论，阅读时需要保留这种区别。

## 资料范围与阅读约定

- 公司、研究、政策与透明度材料以 [Anthropic 官网](https://www.anthropic.com/) 为主。
- Claude API、SDK、产品能力与请求字段以 [Claude Platform 文档](https://platform.claude.com/docs) 及其 API Reference 为主。
- 需要判断模型能力或安全评估时，阅读相关模型的 System Card/Model Report 和评估方法，不从产品宣传文案推导保证。
- 官方页面可能被更新或替换。对模型、价格、产品、API 功能、政策版本等可变信息，课程不固定复述目录，而是在对应课中重新核对。
- 每课把官方原文支持的事实与教学解释、个人推断分开标记。

## 每课格式

1. 本课要回答的问题。
2. 官方页面与关键段落。
3. 核心术语或关系图。
4. 可检查的观察结果或最小练习。
5. 简化点、证据范围和易混淆的边界。

## 课程终点

完成后应能：

- 解释 Anthropic 官网不同资料入口的用途。
- 区分公司自述、研究结果、政策承诺、模型评估和 API 行为。
- 从当前官方文档找到 Claude 产品或开发问题的下一步资料。
- 对可变内容注明日期、版本与适用范围，不把旧快照描述成当前状态。
