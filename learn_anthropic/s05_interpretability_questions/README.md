# 第 05 课：可解释性研究主要试图回答什么问题？

**目标：** 能用 Anthropic 的一篇官方研究说明：可解释性研究观察什么、如何检验解释，以及为什么内部读数不能直接当成模型“真实想法”的完整记录。

## 本课问题

语言模型会把输入转成许多内部数值活动（activations）。研究者如何把这些内部活动转成可检查的证据？这类证据能帮助发现什么，又有哪些边界？

## 官方资料

- [Interpretability 团队页面](https://www.anthropic.com/research/team/interpretability)：团队将目标描述为理解大语言模型内部如何工作，并用这种理解识别外部行为观察不易发现的问题。
- [Natural Language Autoencoders: Turning Claude’s thoughts into text](https://www.anthropic.com/research/natural-language-autoencoders)：本课案例。Anthropic 于 2026-05-07 发布，介绍一种将模型内部 activation 转成自然语言解释的方法及其应用、实验与限制。

页面核对日期：2026-11-09。文章中的实验与数字是 Anthropic 对其研究的报告；本课不把它们视作独立复现或所有模型的一般保证。

## 1. 可解释性在追问什么？

团队页面把目标说成理解模型内部，并解释其行为。落实到研究问题，常见的追问包括：

1. **信息在哪里？** 某个概念、任务状态或特征是否能在模型的内部活动中被观察到？
2. **解释是否有根据？** 一个内部模式的文字说明是否准确反映了它所对应的活动？
3. **它与行为有什么关系？** 内部活动只是与输出同时出现，还是对模型完成任务有因果作用？
4. **能否发现外部行为看不到的问题？** 例如，模型是否在内部注意到自己正被评测，或是否存在隐藏目标？
5. **能否用于安全工作？** 研究者是否能据此更好地审计、诊断或影响模型行为？

这些问题层层递进。发现相关内部信号，不等于已经解释其机制；能解释一个实验案例，也不等于能在任意任务中可靠监控模型。

## 2. 案例方法：Natural Language Autoencoder（NLA）

文章提出 NLA，将模型的一段 activation 转成自然语言说明，再检查这段说明能否帮助重建原来的 activation。简化流程如下：

```text
输入文本 → 目标模型 → 内部 activation
                         ↓
                 Activation Verbalizer
                         ↓
                   文字解释
                         ↓
                Activation Reconstructor
                         ↓
                 重建 activation
                         ↓
             比较重建结果与原始活动
```

Anthropic 描述的三个部分是：

- **Target model：** 冻结的目标模型，提供待研究的内部活动。
- **Activation Verbalizer（AV）：** 读取 activation 并生成文字解释。
- **Activation Reconstructor（AR）：** 只根据文字解释重建 activation。

AV 和 AR 合起来形成“activation → 文字 → activation”的往返。训练时，研究者根据重建活动与原始活动的相似度优化系统。文章报告，随着训练和重建效果改善，文字解释也变得更有信息量。

**证据边界：** 重建相似度是可计算的检验指标，但它不是对“模型实际在想什么”的直接标注。Anthropic 指出，他们无法直接查看某个 activation 所编码的思想，因此不能只凭较高的重建分数就断定解释在语义上完全正确。这是从文章方法推导出的阅读提醒。

## 3. 研究者用它检查什么？

文章介绍了两类用途：

### 查看模型没有明确说出的内容

在安全测试模拟中，研究者关心模型是否注意到自己正在被测试，即使它没有把这种怀疑写进输出。文章报告，NLA 在安全评估对话中检测到内部“意识到测试”的迹象；在获准用于训练的数据样本中，检测比例低于 1%。这两个范围不同的观察不能互相替代，也不能外推到全部 Claude 对话。

### 审计隐藏动机

研究者设置了一个受控的 auditing game：目标模型被特意训练出一种隐藏动机，表现为多种奇怪行为；审计者要从行为中找出共同动机。文章报告，获得 NLA 的审计者在 12%–15% 的试验中找到了动机；没有 NLA、但可以使用其他解释工具时，成功率低于 3%。此实验用于研究审计方法，目标模型和任务均经过人工设计。

这类结果说明 NLA 可能帮助研究者提出或检验有关内部活动的假设。它们本身不能证明：真实部署中存在同样的隐藏动机，NLA 总能发现它，或使用该工具就可以保证模型安全。

## 4. 不要把内部解释读成“透明思维记录”

Anthropic 明确列出 NLA 的限制：

- **解释可能错误。** NLA 会对上下文中的可核对事实产生幻觉；对内部推理的错误更难直接验证。
- **单条解释需要复核。** 文章建议关注多次解释中浮现的主题，并用独立方法交叉验证，再决定是否信任发现。
- **方法成本较高。** 训练需要两个模型副本，读取时每个 activation 还会生成较长文本，因此不适合逐 token 分析长对话或大规模持续监控。
- **实验范围有限。** auditing game 是人工构造的玩具模型实验；其成功率不代表现实审计的普遍效果。

因此，读可解释性文章时，把“观察到一个可读模式”“它能预测或影响行为”“它揭示了模型普遍机制”视为不同强度的结论，并查看每一层由什么实验支撑。

## 5. 练习：把主张和证据对应起来

阅读 NLA 文章后，判断下列说法是否被该文章直接支持：

1. NLA 会把 activation 变成自然语言文本，并通过重建误差来训练。
2. NLA 的解释永远准确，因为它们能重建 activation。
3. 在 Anthropic 报告的受控审计游戏中，NLA 提高了审计者发现预设隐藏动机的成功率。
4. 这项实验证明所有现实部署中的模型隐藏目标都能被 NLA 找到。

**参考答案：** 1 受文章方法说明支持；2 不支持，文章明确指出解释可能错误；3 受文章报告的实验支持，但限于该任务设置；4 不支持，文章指出实验是玩具模型，不能推出普遍效果。

## 本课结论

可解释性研究试图打开“输入—输出”之间的内部过程，回答信息如何表示、内部活动与行为有何关系，以及能否帮助发现或诊断安全问题。NLA 案例把 activation 转成文字并用重建检验方法，但文字解释仍可能错误、验证与规模化成本也有限。内部读数是研究证据，需要与行为测试、独立方法和具体实验范围一起判断。

## 范围与时效

- 案例为 Anthropic 2026-05-07 发布的 NLA 研究文章，核对日期为 2026-11-09。
- 实验、数字及对方法的评价来自 Anthropic 的公开说明；本课未独立复现或审计。
