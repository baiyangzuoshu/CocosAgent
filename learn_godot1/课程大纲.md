# learn_godot1 课程大纲

## 课程目标

以本地 `engine/godot-1.1/` 源码快照为依据，追踪 Godot 1.1 的启动、对象注册、脚本、节点树、资源、输入、渲染、物理和编辑器实现。每课以 C++ 调用链为主，再用兼容 Godot 1.1 工程格式的最小 GDScript 项目观察公开行为。

Godot 1.1 属于早期架构：本课程使用 `ObjectTypeDB`、`SceneMainLoop`、`VisualServer`、`PackedScene::instance()` 等本代概念，不套用 Godot 3/4 的 `ClassDB`、`SceneTree`、`RenderingServer` 或新式项目格式。源码元数据和可用的 1.1 工具用于版本确认；不假设存在现代版本查询 API。

## 实现约定

- 每课独立放在 `sNN_主题/`，尽量按源码职责组织文件；每课实验是可单独打开的最小项目。
- GDScript 实验用于观察本代公开行为；不在脚本中仿写引擎内部机制。
- 每课记录问题、源码文件与关键函数、实验入口、预期观察、简化范围、运行命令和验证环境。
- 旧版工程格式、脚本语法和可执行工具必须以 Godot 1.1 为准；运行结果与静态源码证据分开记录。
- `engine/godot-1.1/` 是只读上游快照；运行或构建前先核对工具链和目标平台。
- 不提交编辑器缓存、构建产物和本机生成文件。

## 证据边界

源码阅读只说明 1.1 快照中的实现职责。旧版工具运行、编辑器交互和目标平台导出分别记录实际版本与环境；未执行的实验不标记为运行验证，也不以 Godot 新版本行为补足旧版结论。
