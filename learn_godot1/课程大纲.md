# learn_godot1 课程大纲

## 课程目标

以仓库本地 `engine/godot-1.1/`（`1.1 stable`）为依据，沿 C++ 源码追踪 Godot 启动、帧循环、对象类型、Variant 和脚本调用。S00–S30 每课配有独立的最小 Godot/GDScript 项目，用来观察对应版本公开行为。

本代边界：旧版工程使用 engine.cfg / 文本 .xml 场景；S00 不依赖现代 Engine.get_version_info()。

## 课次结构

- 每课先提出一个可由源码回答的问题，列出关键函数、参数/状态传递和调用顺序。
- S00–S10 与 S21–S30 的 `src/upstream/` 收录本课涉及的完整 C++ 文件副本及带原始行号的函数摘录；S00–S10 的完整副本另由各课 SHA-256 清单校验。S11–S20 保留关键 C++ 摘录。所有原文可回到只读 `engine/` 快照核对。
- 每课项目独立可打开；S00–S10 与 S21–S30 增加按 Godot 大版本分别编写的 GDScript 源码教学模型，并用真实引擎 API 实验对照公开行为。模型明确标注简化边界，不替代 C++ 实现。
- README 将静态源码结论、预期输出、实际运行记录和简化边界分开；没有运行记录时不声称已验证。

## 证据边界

源码阅读只说明 1.1 快照中的实现职责。旧版工具运行、编辑器交互和目标平台导出分别记录实际版本与环境；未执行的实验不标记为运行验证，也不以 Godot 新版本行为补足旧版结论。
