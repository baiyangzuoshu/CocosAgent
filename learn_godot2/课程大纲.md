# learn_godot2 课程大纲

## 课程目标

以本地 `engine/godot-2.1/` 源码快照（Godot 2.1.7-rc）为依据，追踪平台启动、`ObjectTypeDB`、GDScript、`SceneTree`、资源、输入、`VisualServer`、物理和编辑器实现。每课以 C++ 源码调用链为主，并配套一个最小 Godot 2.1/GDScript 实验观察运行行为。

本课程保留 Godot 2.1 的 `SceneTree::iteration()`、`PackedScene::instance()`、`VisualServer`、`Physics2DServer`/`PhysicsServer`、`AnimationTreePlayer` 和旧版导入导出流程。课程只引用本快照中能确认的 API，不套用 Godot 3/4 的 `ClassDB`、`RenderingServer`、`instantiate()` 等后续命名。

## 实现约定

- 每课放在独立 `sNN_主题/` 目录，以本代项目格式组织一份可单独运行的最小实验。
- 实验观察 GDScript 可见行为；源码追踪记录关键 C++ 文件、函数和调用方向。
- 每课记录问题、实验入口、可观察结果、简化边界、运行命令与 Godot 工具版本。
- 静态源码、工具运行、编辑器交互和导出结果分别记证据；没有执行的结果不作推断。
- `engine/godot-2.1/` 是只读上游快照；运行、构建或安装额外依赖前先核对工具链。
- 不提交 `.godot/`、构建输出或其他缓存产物。

以下课次是第一版规划。每课开始时再按源码确认入口及关键调用；如果实验需要多个步骤，仍保持每课可单独复现。

## 证据边界

课程结论只对应 Godot 2.1.7-rc 快照。旧版编辑器和运行时的实际可执行情况取决于本机系统与兼容工具；源码阅读、实验运行和导出验证需分别记载，不以新版行为替代未验证结果。
