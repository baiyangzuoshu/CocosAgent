# learn_openai 课程总纲

## 课程目标

从 OpenAI 官方资料建立完整的开发者知识路径：先理解模型、提示和 API 基础，再学多模态输入、工具和 Agents，最后掌握评估、上线与优化。

课程按知识依赖逐步增加。表中每一项是一课的核心问题，不把整个专题压在一节里。各课的官方页面、示例和范围说明写在对应课程 README 中。

## 资料范围

- 以 [OpenAI Learn](https://developers.openai.com/learn) 的学习轨道和 [API Platform 文档](https://developers.openai.com/api/docs) 为主。
- 查请求字段、返回结构和 API 共同行为时使用 [API Reference](https://developers.openai.com/api/reference/overview)。
- 以官方页面为事实依据；教程、示例和解释用于帮助理解，不覆盖官方定义。
- 模型、价格、API 状态、产品可用性和弃用时间可能变化，在对应课程开始时重新核对。

## 每课格式

1. 本课要回答的问题。
2. 官方文档页面及关键章节。
3. 本课新增的最小示例或观察练习。
4. 预期结果和核验方法。
5. 简化、限制和容易混淆的边界。
