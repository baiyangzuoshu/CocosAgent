# 第 7 课：向量、矩阵与齐次坐标

本课手算一个二维点经过缩放、旋转和平移后的坐标，再用 C++ 的 4×4 矩阵乘法算出同一结果。窗口用青色标出输入点，用橙色标出变换后的点；终端打印中间值和最终坐标。

## 学完后你能

- 把点写成齐次坐标 `(x, y, z, 1)`，把方向向量写成 `(x, y, z, 0)`。
- 用列向量约定组合缩放、旋转和平移矩阵。
- 解释复合矩阵 `T * R * S` 为什么按从右往左作用。

## 手算一个点

输入点是 `p = (0.4, 0.2, 0, 1)`，按顺序缩放、绕 Z 轴旋转 90°，再平移 `(0.3, -0.1)`：

```text
缩放后：S * p         = (0.6, 0.2, 0, 1)
旋转后：R * S * p     = (-0.2, 0.6, 0, 1)
平移后：T * R * S * p = (0.1, 0.5, 0, 1)
```

因此复合矩阵写作 `M = T * R * S`。列向量从右侧相乘，所以最右边的 `S` 先作用。窗口在坐标网格中同时画出输入点和最终点；终端会打印每一步坐标，便于和手算对照。

## 运行

需要 CMake 3.20 或更新版本、C++17 编译器、OpenGL 开发库、GLFW 3，以及为 OpenGL 3.3 Core 生成的 GLAD 1。依赖由本机提供，课程不会自动下载或安装。

在本目录运行：

```sh
cmake -S . -B build
cmake --build build
./build/learn_opengl_s07_vectors
```

窗口中青色点是输入点，橙色点是变换后的点，细线连接两者。按 Esc 关闭窗口；坐标值输出在启动程序的终端。

## 跟着代码走

### 齐次坐标

程序用四个分量保存点：

```cpp
Vec4 point{ 0.4F, 0.2F, 0.0F, 1.0F };
```

变换矩阵左乘列向量。平移量位于矩阵最后一列：

```text
T = | 1  0  0  tx |
    | 0  1  0  ty |
    | 0  0  1  tz |
    | 0  0  0   1 |
```

点向量最后一个分量 `w=1` 让平移参与变换。相同的 `(x, y, z)` 若代表方向，写成 `w=0`，平移项相乘后为零；程序也会打印这个方向经过复合矩阵后的结果。

### 矩阵乘法

示例按列主序存储矩阵，但通过 `at(row, column)` 访问时仍按通常的行列形式计算。矩阵乘法使用：

```text
(A * B)[row, column] = Σ A[row, k] * B[k, column]
```

不要把存储顺序和乘法顺序混为一谈：列主序说明元素如何放进内存；`M * p` 说明矩阵如何作用于列向量。

## 动手观察

1. 把平移改为 `(0, 0)`，确认输入点和输出点只受缩放、旋转影响。
2. 交换复合顺序，例如计算 `S * R * T * p`，对比终端坐标和窗口位置。
3. 将点的 `w` 改为 `0`，观察平移为何不再改变它；再恢复 `w=1`。
4. 修改缩放矩阵中的一个对角值，先手算，再和终端输出核对。

## 检查理解

- 为什么二维点通常扩展成四维齐次坐标，而不是只保存 `(x, y)`？
- `T * R * S * p` 中哪一个矩阵先作用？
- 改变内存中的列主序存储，是否会改变 `T * R * S` 的数学顺序？
- 当 `w=0` 时，平移矩阵为什么不会改变方向向量？
