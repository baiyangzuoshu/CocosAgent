# Learn OpenGL 课程大纲

## 目标

先通过独立练习掌握 GPU 绘制的基本对象和状态，再沿 Cocos 源码从场景、相机和渲染队列追到图形后端。课程观察的是本地引擎源码快照；引擎行为和平台范围以各专题记录为准。

## 课程

| 课次 | 练习主题 | 练习结果 | 引擎源码对照 |
| --- | --- | --- | --- |
| 1 | OpenGL 上下文、着色器、VAO/VBO、绘制调用 | 窗口中绘制一个三角形 | `engine/cocos2d-x-4/cocos/renderer/backend/opengl/BufferGL.cpp`、`ProgramGL.cpp`、`CommandBufferGL.cpp`；Creator 3.8.7 `cocos/gfx/webgl2/webgl2-commands.ts` |
| 2 | 顶点属性、索引缓冲和纹理采样 | 绘制带纹理的矩形 | Cocos2d-x `BufferGL.cpp`、`TextureGL.cpp`；Creator 3.8.7 `cocos/gfx/webgl2/webgl2-texture.ts` |
| 3 | 模型、观察和投影变换 | 旋转并观察 3D 物体 | Creator 2.4.15 `cocos2d/renderer/scene/camera.js`、`cocos2d/renderer/renderers/forward-renderer.js`；Creator 3.8.7 渲染专题 |
| 4 | 深度测试、面剔除、混合和模板状态 | 比较不同深度与混合状态 | Cocos2d-x `DepthStencilStateGL.cpp`、`CCRenderState.cpp` |
| 5 | 法线、光照和材质 | 为模型加入基础光照 | Cocos2d-x renderer 的 shader 与 material；Creator 2.4.15/3.8.7 的材质和 Pass 路径 |
| 6 | 帧缓冲和多阶段绘制 | 将场景画入纹理并做简单后处理 | Cocos2d-x `CommandBufferGL.cpp` 的 RenderPass；Creator 3.8.7 RenderGraph 与 GFX 命令路径 |
| 7 | 相机裁剪、排序与批处理 | 观察场景变化怎样影响绘制提交 | Creator 2.4.15 `RenderFlow`、`ModelBatcher`、`ForwardRenderer`；Creator 3.8.7 `RenderScene`、RenderGraph 和 `Batcher2D` |

## 第一阶段：绘制基础

第 1 课从 GPU 绘制所需的最小对象开始：OpenGL 上下文、顶点着色器、片段着色器、顶点数组、顶点缓冲和一次绘制调用。之后逐步加入顶点属性、索引和纹理。

对照 Cocos2d-x 4.0 的 `CommandBufferGL.cpp` 时，重点看 `prepareDrawing`、`bindVertexBuffer`、`drawArrays` 和 `drawElements`。这些函数展示引擎如何把管线、顶点缓冲和 Draw 调用接到 OpenGL。Creator 3.8.7 的 `webgl2-commands.ts` 展示相似职责如何经过 GFX 抽象后落到 WebGL2。

## 第二阶段：场景与渲染状态

增加矩阵、相机、深度测试、剔除、混合、材质和光照。每课先在练习中观察一个状态，再从引擎源码追踪对应资源、Pass 或后端调用。

## 第三阶段：渲染管线

通过帧缓冲、RenderPass 和简单后处理理解多阶段绘制；随后阅读引擎中的相机收集、可见性裁剪、渲染队列、命令录制和提交。2.4.15、3.8.7 与 Cocos2d-x 4.0 的实现分别记录，平台差异单列。

## 证据边界

- 练习代码的运行结果只证明当前机器和图形上下文中的行为。
- 源码阅读结论注明引擎版本和文件位置。
- 桌面 OpenGL 练习不能直接证明 Creator Web、Native 或小游戏后端的运行行为。
- 跨版本对照使用仓库专题：[2.4 渲染研究](../docs/2.x/06-graphics-rendering.md)、[3.8 渲染研究](../docs/3.x/06-graphics-rendering.md)、[图形渲染对照](../docs/comparisons/06-graphics-rendering.md)。
