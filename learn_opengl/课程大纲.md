# Learn OpenGL 课程大纲

## 目标

先通过小型独立练习掌握 OpenGL 绘制，再沿 Cocos 源码从图形资源和命令追到完整帧流程。总纲分成 6 个阶段、30 课；每课聚焦一个主要概念和一个可观察结果。当前已实现第 1–12 课，其余课次是学习计划，后续按进度逐课补充。

桌面练习以 C++17、OpenGL 3.3 Core Profile、GLFW 和 GLAD 为基础。Cocos 源码用于解释引擎中的对应职责；源码结论以仓库中的具体版本和平台证据为界。

## 每课约定

每课逐步补齐以下内容：本课问题、可读源码位置、独立练习、可观察结果、简化点和证据范围。已实现课程放在独立的 `sNN_主题/` 目录；未实现的课程只在本总纲中规划，不代表已有代码或运行验证。

## 证据边界

- 练习的运行结果只证明当前机器和 OpenGL 上下文中的行为。
- 源码阅读结论注明引擎版本和文件位置。
- 桌面 OpenGL 练习不能直接证明 Creator Web、Native 或小游戏后端的运行行为。
- Creator 3.8 的当前渲染专题只覆盖已注明的 WebGL Builtin 路径；原生后端和自定义管线需要单独验证。
