# learn_langchain 课程大纲

## 课程目标

以 `AI/langchain-master/` 中的本地 Python 源码快照为依据，追踪 LangChain 1.x 从基础组合协议到高层 Agent 的职责分层。通过逐课可运行的精简示例看清关键对象、数据形状、调用顺序和扩展边界。

初版共 30 节：主线第 0–26 课共 27 节，`langchain-classic` 历史附篇 A1–A3 共 3 节。

版本依据：`libs/langchain_v1/pyproject.toml`、`libs/core/pyproject.toml` 与 `libs/langchain/pyproject.toml`。本地快照分别标注 `langchain 1.5.0`、`langchain-core 1.8.1`、`langchain-classic 1.0.8`；三者的 Python 要求均为 `>=3.11.0,<4.0.0`。

## 实现约定

- 每课放在 `sNN_主题/`，代码用 Python 表达，路径尽量对应源码包的职责。
- 每课解决一个问题，列出源码文件和关键类型/方法，并给出可观察输出。
- 示例应独立运行；按课程需要使用标准库、假模型和内存实现，避免把外部 API 或凭据作为基础课前置条件。
- 课程示例只保留当前主题所需行为，不声称与 LangChain 源码完全兼容；简化边界写在课内。
- 课程主线讲 `langchain-core` 与 `langchain` 1.x；`langchain-classic` 放在历史附篇。
- Agent 课程追踪 LangChain 如何使用 LangGraph 组装和运行 Agent；LangGraph 的图执行、持久化和中断运行时留给独立课程。

## 源码分层

| 层 | 本地目录 | 课程关注点 |
| --- | --- | --- |
| `langchain-core` | `AI/langchain-master/libs/core/langchain_core/` | Runnable、消息、Prompt、模型协议、Tools、回调、文档与检索抽象 |
| `langchain` | `AI/langchain-master/libs/langchain_v1/langchain/` | `init_chat_model`、Agent 工厂、结构化输出、Middleware、MCP 适配 |
| Provider 集成 | `AI/langchain-master/libs/partners/` | 以一个 provider 为例观察接口实现边界，不穷举集成包 |
| 文本切分 | `AI/langchain-master/libs/text-splitters/` | 将文本切分算法作为检索流水线的独立组件观察 |
| 历史包 | `AI/langchain-master/libs/langchain/langchain_classic/` | 旧 Chain、Memory 和迁移边界 |
| LangGraph | `AI/langgraph-main/` | 本课程只追踪 Agent 对图运行时的调用边界 |

课次表中 `libs/` 开头的目录相对于 `AI/langchain-master/`。省略上级目录的 Core 模块路径（例如 `runnables/base.py`）相对于 `AI/langchain-master/libs/core/langchain_core/`；Agent 模块路径（例如 `agents/factory.py`）相对于 `AI/langchain-master/libs/langchain_v1/langchain/`；`langchain/mcp/` 和 `langchain/tools/` 开头的路径相对于 `AI/langchain-master/libs/langchain_v1/`；`langchain_classic/` 开头的路径相对于 `AI/langchain-master/libs/langchain/`。

## 运行准备

- Python 3.11 或更新版本。
- 第 0 课只使用标准库 `tomllib`，不需要安装 Python 包、配置 API Key 或访问网络。
- 后续涉及真实模型或托管服务的观察会单独注明凭据、依赖和平台条件；基础示例优先使用假模型及内存实现。
