# Cocos2d-x 1.0–4.0 源码演进

这门课程用仓库中的四份 C++ 引擎快照梳理 Cocos2d-x 的架构变化。同一主题按版本分别阅读，保留各代源码自己的类名和目录结构。

## 源码快照

| 代际 | 本地版本标记 | 快照日期 | 源码位置 |
| --- | --- | --- | --- |
| 1.x | `cocos2d-1.0.1-x-0.13.0-beta` | 2012-03-30 | `engine/cocos2d-x-1/` |
| 2.x | `cocos2d-x-2.2.6` | 2014-12-12 | `engine/cocos2d-x-2/` |
| 3.x | `cocos2d-x-3.17.2` | 2019-05-21 | `engine/cocos2d-x-3/` |
| 4.x | `cocos2d-x-4.0` | 2019-12-03 | `engine/cocos2d-x-4/` |

版本标记取自各快照的 `CHANGELOG`。这些是课程选用的源码样本，不代表每个小版本都包含在本地。
