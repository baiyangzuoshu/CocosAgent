# Cocos2d-x 1.x–4.0 源码演进课程大纲

## 课程目标

沿同一批引擎职责阅读不同年代的 C++ 源码，逐步看清目录、对象模型和运行流程如何演进。每课只增加一个概念，并给每个版本一份独立的精简代码；目录与类名跟随该版本源码。

## 源码里已能确认的变化

- 1.x/2.x 主要引擎目录为 `cocos2dx/`，核心类常带 `CC` 前缀，基础对象名为 `CCObject`。
- 3.x/4.x 主要引擎目录为 `cocos/`，基础对象改名为 `Ref`，并使用 `Node`、`Scene`、`Director` 等类型名。
- 3.x/4.x 有独立的 `cocos/renderer/`；1.x/2.x 没有这个目录。渲染职责的具体变化会在对应课程里沿调用路径核实。
- 4.0 的变更记录突出 Metal 支持和所有平台使用 CMake；这是 4.0 快照的记录，不外推到早期版本。

核心类型声明位置：

- 2.x：`engine/cocos2d-x-2/cocos2dx/cocoa/CCObject.h:59`、`engine/cocos2d-x-2/cocos2dx/base_nodes/CCNode.h:128`、`engine/cocos2d-x-2/cocos2dx/layers_scenes_transitions_nodes/CCScene.h:49`、`engine/cocos2d-x-2/cocos2dx/CCDirector.h:97`。
