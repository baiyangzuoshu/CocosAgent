# learn_2.4cocoscreator 课程大纲

## 课程目标

以 Creator 2.4.15 源码为依据，用 TypeScript 逐步实现一份精简的 Web 浏览器运行时。通过保留源码的模块边界、职责和调用顺序，学习引擎架构；只实现当前课程需要的代码。

版本依据：`engine/2.4.15engine/package.json` 中的 `2.4.15`。

## 实现约定

- 每课代码放在各自的 `sNN_主题/` 目录中；其中的 `src/` 尽量镜像源码，例如 `s02_game_startup/src/cocos2d/core/CCGame.ts` 对应 `engine/2.4.15engine/cocos2d/core/CCGame.js`。
- 保留所选 Web 运行路径的模块边界、类职责、注册顺序和关键调用链；删减无关平台、编辑器和当前课程未涉及的功能。
- 每课目录保存一份可独立运行的完整代码快照。后一课以此前实现为基础，只增加当前功能；每课都能单独阅读和运行。
- TypeScript 用于表达课程实现；不以完整兼容 Creator 2.4.15 为目标。简化点和省略的源码分支须写明。
- 首轮聚焦 Web 浏览器运行时。渲染部分沿 2.4.15 的 Web 路径逐步实现，先覆盖最小可观察功能。

## 每课格式

1. 本课要理解的一个问题。
2. 对应的源码文件和关键函数。
3. 本课目录内的独立代码，以及相对前一课增加的功能。
4. 一个可观察的运行结果。
5. 必要时用一两句话说明裁剪内容。

同一源码文件可以拆成多课；每课只讲清当前新增的一层。

## 课程顺序

### 第一阶段：从模块入口到帧循环

| 课 | 增量内容 | 2.4.15 源码对照 | 阶段结果 |
| --- | --- | --- | --- |
| 0 | 建立最小 TypeScript 浏览器宿主和运行入口 | 课程代码：`s00_web_entry/` | 页面能启动课程代码 |
| 1 | 装配模块，建立 `cc` 命名空间和模块注册顺序 | `index.js`、`cocos2d/core/predefine.js` | 入口能装配所需模块 |
| 2 | 加入游戏启动流程和引擎初始化 | `cocos2d/core/CCGame.js`：`run`、`_prepareFinished`、`_initEngine` | 观察游戏启动和初始化事件顺序 |
| 3 | 加入 Director 初始化和主循环 | `cocos2d/core/CCDirector.js`：`init`、`mainLoop`；`CCGame.js`：`_runMainLoop` | 页面持续产生帧更新 |

| 课 | 增量内容 | 2.4.15 源码对照 | 阶段结果 |

| 4 | 节点父子关系和场景树 | `cocos2d/core/utils/base-node.js`、`cocos2d/core/CCNode.js`、`cocos2d/core/CCScene.js` | 能创建并遍历一棵节点树 |
| 5 | 局部变换、父子变换和活动状态 | `cocos2d/core/CCNode.js`、`cocos2d/core/utils/base-node.js` | 子节点位置随父节点变换 |
| 6 | 场景加载后的节点激活 | `cocos2d/core/CCScene.js`、`cocos2d/core/node-activator.js` | 场景进入运行状态时节点被激活 |
