# OpenAI Agents Python SDK 源码学习大纲

## 学习目标

以 `engine/openai-agents-python-main/` 为源码依据，读懂 SDK 如何将 Agent 配置、模型调用、工具执行、工作流切换与运行结果组合起来，并了解状态保存和外部运行时接入的位置。

## 每课格式

1. 本课要回答的问题。
2. 本地源码文件和关键函数。
3. 一个可独立阅读或运行的最小示例。
4. 能观察或判断的结果。
5. 简化点与版本边界。

课程示例优先使用 SDK 的 `ScriptedModel`，验证运行编排时不需要调用真实模型；接入外部模型、MCP 服务、语音服务或 Sandbox 时，再单独说明依赖和凭据。

| 课 | 增量主题 | 源码入口 | 阶段结果 |
| --- | --- | --- | --- |
| 0 | 包目录、公开 API、核心模块与阅读路线 | `pyproject.toml`、`README.md`、`src/agents/__init__.py`、`src/agents/` | [从仓库地图选出阅读入口](s00_repository_map/README.md) |
| 1 | 配置 Agent 并通过 Runner 得到结果 | `src/agents/agent.py`：`Agent`；`src/agents/run.py`：`Runner.run`、`run_sync`；`src/agents/result.py`：`RunResult` | [观察固定模型响应如何变成 `final_output`](s01_agent_runner/README.md) |
| 2 | 模型接口、Provider 与模型选择 | `src/agents/models/interface.py`、`models/multi_provider.py`、`run_internal/turn_preparation.py`：`get_model` | 解释 SDK 怎样从 Agent 或 RunConfig 选择模型 |

| 4 | 单轮结果如何决定继续、交接、暂停或结束 | `src/agents/run_internal/run_steps.py`、`run_internal/run_loop.py`、`src/agents/run.py` | 区分最终输出、工具再运行、handoff 与审批中断 |
