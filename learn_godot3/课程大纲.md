# learn_godot3 课程大纲

## 课程目标

以本地 `engine/godot-3.6/` 源码快照（Godot 3.6.4-rc）为依据，追踪 Godot 3 的启动循环、`ClassDB`、GDScript、`SceneTree`、资源、输入、`VisualServer`、物理、多人游戏和扩展接口。每课以 C++ 源码调用链为主，并配套一个最小 Godot 3/GDScript 实验观察运行行为。

本课程保留 Godot 3.6 的 `Reference`、`PackedScene::instance()`、`VisualServer`、`Physics2DServer`/`PhysicsServer`、`AnimationTree`、`MultiplayerAPI` 和 GDNative 等本代边界。Godot 4 的 `RefCounted`、`RenderingServer`、`instantiate()`、新 Multiplayer API 与 GDExtension 不用于描述本快照。

## 实现约定

- 每课独立放在 `sNN_主题/`，每个实验是可单独打开和运行的最小 Godot 3 项目。
- GDScript 用于观察引擎公开行为；C++ 源码用于解释实现调用链，不在实验中仿写引擎内部机制。
- 每课记录问题、源码文件和关键函数、实验入口、可观察结果、简化范围、运行命令及工具版本。
- 将静态源码、编辑器交互、Godot 运行时、导出和目标平台证据分开记录。
- `engine/godot-3.6/` 是只读上游快照；运行、构建或准备额外工具链前先核对本机条件。
- 不提交 `.godot/`、构建输出及其他本机缓存。

## 证据边界

课程结论只描述 Godot 3.6.4-rc 快照中的实现。Godot 3 项目的编辑器行为、脚本兼容性、导出和目标平台运行分别记录实际工具与环境；未执行的步骤不作为验证结果，也不推广到 Godot 4。
