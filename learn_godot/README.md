# Godot 源码学习课程

Godot 1.1、2.1、3.6、4.7 分别设课，依据各自的本地源码快照。当前整理范围是四代课程的 S00–S10。

每课采用 **C++ 源码追踪 + 最小 Godot/GDScript 实验**：先沿调用链读本课摘录，再运行独立项目观察脚本层行为。课程摘录保留上游 C++ 行段和原始行号；完整源码上下文以只读 `engine/` 快照为准。实验未记录实际运行环境与输出时，只列为预期观察。
