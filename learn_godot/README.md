# Godot 源码学习课程

Godot 1.1、2.1、3.6、4.7 分别设课，依据各自的本地源码快照。四代已编写课程范围为 S00–S20。

每课以 **C++ 源码追踪 + 最小 Godot/GDScript 实验** 为主：从对应版本的源码摘录逐段追踪调用，再运行独立项目观察脚本层行为。课程摘录保留上游 C++ 行段和原始行号；完整源码上下文以只读 `engine/` 快照为准。实验未记录实际运行环境与输出时，只列为预期观察。

| 课程 | 源码快照 | 版本标记 | 课程入口 |
| --- | --- | --- | --- |
| Godot 1 | `engine/godot-1.1/` | 1.1 stable | [S00–S20](../learn_godot1/README.md) |
| Godot 2 | `engine/godot-2.1/` | 2.1.7-rc | [S00–S20](../learn_godot2/README.md) |
| Godot 3 | `engine/godot-3.6/` | 3.6.4-rc | [S00–S20](../learn_godot3/README.md) |
