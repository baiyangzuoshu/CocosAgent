# Godot 4.8.0 源码学习

本课程以仓库中的 `engine/godot-master/` 为源码依据。该快照的 `version.py` 标记为 Godot 4.8.0 beta；课程结论只适用于这份本地快照和每课实际记录的平台。

课程采用 **C++ 源码追踪 + 最小 Godot/GDScript 实验**：读源码中的职责和调用顺序，再用真实 Godot 项目观察可见行为。实验用于验证公开行为，不重写或模拟引擎内部实现。

## 学习方式

1. 从[课程大纲](课程大纲.md)选择课次。
2. 阅读课内列出的 C++ 文件、关键函数和调用关系。
3. 在本课独立 Godot 项目中运行 GDScript 实验，观察记录的结果。
4. 对照源码解释结果，并区分静态源码、实际运行、编辑器行为和平台验证。

每课独立运行，不依赖前一课。课程文件夹计划采用 `sNN_主题/`；课内 README 说明问题、源码入口、实验项目、观察结果、简化范围和运行方法。

## 版本与运行

课程按本地快照 `engine/godot-master/version.py` 标记的 **4.8.0 beta** 规划。`master` 会继续变化；更新课程依据时，应重新确认源码版本，并记录课程结论是否仍适用。

运行实验前核对本机 Godot 编辑器或命令行工具版本。每课给出实际命令和目标环境；如果实验未运行或目标平台未验证，会在课内明确标注。课程不默认构建 Godot 引擎，也不下载依赖或安装工具。
