# Godot 源码学习课程

Godot 1.1、2.1、3.6、4.7 分别设课，依据各自的本地源码快照。四代已编写课程范围为 S00–S30。

每课以 **C++ 源码追踪 + 最小 Godot/GDScript 实验** 为主：从对应版本的 C++ 源码副本和函数摘录追踪调用，再运行独立项目观察脚本层行为。S00–S10 与 S21–S30 保留完整上游 C++ 文件副本和原始行号摘录；S00–S10 另带可运行 GDScript 教学模型。完整原文以只读 `engine/` 快照为准。实验未记录实际运行环境与输出时，只列为预期观察。
