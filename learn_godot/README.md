# Godot 源码学习课程

Godot 各代源码分别设课，按对应快照研究，不把某一代的类名、API 或运行结果外推到其他版本。

| 课程 | 源码快照 | 版本标记 |
| --- | --- | --- |
| [Godot 1](../learn_godot1/README.md) | `engine/godot-1.1/` | 1.1 stable |
| [Godot 2](../learn_godot2/README.md) | `engine/godot-2.1/` | 2.1.7-rc |
| [Godot 3](../learn_godot3/README.md) | `engine/godot-3.6/` | 3.6.4-rc |
| [Godot 4](../learn_godot4/README.md) | `engine/godot-4.7/` | 4.7.3-rc |

各版本课程采用 C++ 源码追踪和对应版本的最小 Godot/GDScript 实验。实验工程格式、脚本能力和运行工具按该版本分别确认。
