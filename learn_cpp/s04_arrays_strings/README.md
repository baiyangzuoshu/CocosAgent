# 第 4 课（C03）：数组与 C 风格字符串

**目标：** 用数组保存一组同类型数据，按下标访问元素，并理解 C 字符串是以 `\0` 结尾的字符数组。

## 本课问题

- 数组如何连续保存多个同类型元素？
- 数组下标从哪里开始，合法范围是什么？
- 字符数组的容量和当前字符串长度有什么区别？
- 结束标记 `\0` 在 C 字符串中起什么作用？

## 示例程序

程序遍历一组分数并求和，然后遍历字符数组，直到遇到字符串结束标记 `\0`。

~~~c
int scores[] = {12, 18, 15};
size_t score_count = sizeof(scores) / sizeof(scores[0]);

char title[12] = "C arrays";
~~~

完整程序位于 `src/main.c`。

## 编译和运行

在本课目录执行：

~~~sh
cc -std=c17 -Wall -Wextra -Wpedantic -Werror \
  src/main.c \
  -o /tmp/learn-cpp-s04
/tmp/learn-cpp-s04
~~~

预期输出：

~~~text
scores: 12 18 15
total: 45
title: C arrays
length: 8
capacity: 12
updated title: c arrays
~~~

## 观察要点

- `scores` 的三个元素在内存中连续排列，合法下标是 `0`、`1`、`2`。
- `sizeof(scores) / sizeof(scores[0])` 在数组仍处于定义作用域时可以计算元素个数。
- `title` 有 12 个字符的存储空间；初始化字符串当前包含 8 个可见字符和一个结尾 `\0`。
- C 字符串以 `\0` 表示结束；`printf("%s", title)` 会按这个标记读取字符。
- 本例逐个读取 `title` 的元素，遇到 `\0` 后停止，因此长度为 8；容量为 12。
- 修改 `title[0]` 会改变数组中的字符；修改时要保留结尾 `\0`。

## 简化说明

- 本课数组长度固定，暂不介绍动态分配数组。
- `sizeof` 只有在数组本身可见时才能按整个数组计算；数组作为函数参数时的行为留到指针课程说明。
- C 不会自动检查数组下标。越界访问可能造成未定义行为；C 字符串缺少结尾 `\0` 时，字符串输出也可能继续读取数组范围之外的数据。
- 本课手动计算字符串长度，为后续学习 `strlen` 和指针参数做准备。
