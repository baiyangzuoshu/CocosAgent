# C 与 C++ 源码学习大纲

## 课程目标

先掌握读 C/C++ 引擎源码所需的 C 语言基础，再系统学习现代 C++，最后以仓库中的 Cocos2d-x 4.0 源码作为实践对象。

## 每课格式

1. 本课要理解的问题。
2. 相关概念或本地源码位置。
3. 独立、精简的代码练习。
4. 一个可观察结果。
5. 必要的简化和证据说明。

## 第一阶段：C 语言基础

| 课程 | 主题 | 阶段结果 |
| --- | --- | --- |
| C00 | 编译、运行、源文件与头文件 | 编译并运行由多个源文件组成的 C 程序 |
| C01 | 基本类型、变量、运算与流程控制 | 完成输入、计算和分支程序 |
| C02 | 函数、作用域与多文件组织 | 将程序拆分为多个 `.c` 和 `.h` 文件 |
| C03 | 数组与 C 风格字符串 | 处理数组和字符串缓冲区 |
| C04 | 指针、地址与函数参数 | 观察地址并理解指针参数 |
| C05 | 结构体、枚举与结构体指针 | 描述简单对象及其状态 |
| C06 | 栈、堆、`malloc/free` 与生命周期 | 分配、使用并释放动态内存 |
| C07 | 小练习：简单对象树 | 用结构体和指针表示并遍历对象树 |

## 第二阶段：现代 C++

| 课程 | 主题 | 阶段结果 |
| --- | --- | --- |
| CPP01 | 从 C 到 C++：命名空间、输入输出、`bool`、`nullptr` | 写出基本 C++ 程序并识别主要语言差异 |
| CPP02 | 类型、初始化、`const` 与引用 | 理解常见类型及引用参数 |
| CPP03 | 函数、重载、默认参数 | 设计并调用不同形式的函数接口 |
| CPP04 | `std::string`、`std::array`、`std::vector` | 用标准类型处理文本和顺序数据 |
| CPP05 | `map`、`set` 等关联容器 | 按键组织和查找数据 |
| CPP06 | 迭代器与标准算法 | 遍历、查找和排序容器内容 |
| CPP07 | Lambda 表达式 | 编写可传给算法的操作 |
| CPP08 | `struct`、`class` 与封装 | 用类表达状态和行为约束 |
| CPP09 | 构造函数与初始化 | 创建有效对象并初始化成员 |
| CPP10 | 对象生命周期与析构函数 | 追踪对象的创建和销毁 |
| CPP11 | RAII 与资源管理 | 用对象生命周期管理资源 |
| CPP12 | 拷贝构造与拷贝赋值 | 理解对象复制和资源关系 |
| CPP13 | 移动语义与右值引用 | 理解资源转移和 `std::move` |
| CPP14 | 指针、动态内存与所有权边界 | 区分借用指针和拥有资源的指针 |
| CPP15 | 智能指针 | 使用 `unique_ptr`、`shared_ptr`、`weak_ptr` 表达所有权 |
| CPP16 | 组合与对象关系 | 用组合组织多个对象 |
| CPP17 | 继承与多态 | 理解虚函数、动态派发和虚析构函数 |
| CPP18 | 模板与泛型编程 | 编写可用于多种类型的函数或类 |
| CPP19 | 错误处理与异常 | 设计错误路径并理解异常与 RAII 的配合 |
| CPP20 | 编译、链接、ODR 与综合练习 | 组织多文件程序并完成小型综合项目 |

## 第三阶段：Cocos2d-x 4.0 引擎源码实践

| 课程 | 主题 | 阶段结果 |
| --- | --- | --- |
| ENG01 | 源码版本与目录地图 | 确认本地快照、模块边界和入口 |
| ENG02 | 工程结构、构建目标与依赖 | 看懂源文件和构建目标的组织方式 |
| ENG03 | 平台入口与应用创建 | 跟踪平台入口如何创建引擎应用 |
| ENG04 | Application、AppDelegate 与初始化 | 追踪应用初始化到首个场景准备完成 |
| ENG05 | Director 与场景切换 | 观察 Director 如何管理当前场景 |
| ENG06 | 帧循环与 Scheduler | 追踪逐帧更新和定时回调 |
| ENG07 | Scene、Node 与场景树 | 创建父子节点并遍历层级 |
| ENG08 | 变换与坐标关系 | 观察父节点变换对子节点的影响 |
| ENG09 | Ref、引用计数与 AutoreleasePool | 跟踪对象持有和释放时机 |
| ENG10 | Component 与组件生命周期 | 观察组件挂载、启用和停用流程 |
| ENG11 | 事件分发与输入监听 | 注册监听器、响应输入并移除监听器 |
| ENG12 | Action 与动作管理 | 启动、暂停和停止节点动作 |
| ENG13 | FileUtils 与资源路径解析 | 从逻辑路径追踪到实际文件 |
| ENG14 | TextureCache 与纹理复用 | 观察重复请求如何复用纹理缓存 |
| ENG15 | SpriteFrameCache 与精灵帧 | 追踪精灵帧和纹理资源的关系 |
| ENG16 | Sprite 到渲染器的调用路径 | 跟踪场景节点如何进入渲染流程 |
| ENG17 | UI 组件与布局 | 创建简单界面并观察布局和交互入口 |
| ENG18 | 音频播放与资源生命周期 | 播放、停止音频并追踪资源使用 |
| ENG19 | 物理组件与碰撞回调 | 创建简单物理对象并观察碰撞响应 |
| ENG20 | 综合练习：启动、交互、资源与渲染 | 串联应用启动、场景更新、输入和绘制路径 |

引擎源码实践先依据本地 Cocos2d-x 4.0 快照做静态追踪。运行构建前检查工具链、依赖和目标平台；静态分析、编译和运行时观察分别记录，不互相替代。
