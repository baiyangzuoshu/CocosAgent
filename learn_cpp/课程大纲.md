# C 与 C++ 源码学习大纲

## 课程目标

先掌握读 C/C++ 引擎源码所需的 C 语言基础，再系统学习现代 C++，最后以仓库中的 Cocos2d-x 4.0 源码作为实践对象。

## 每课格式

1. 本课要理解的问题。
2. 相关概念或本地源码位置。
3. 独立、精简的代码练习。
4. 一个可观察结果。
5. 必要的简化和证据说明。
