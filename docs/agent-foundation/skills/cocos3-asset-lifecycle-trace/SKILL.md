# Trace 3.8.7 asset lifetime

Confirm Creator 3.8 and the runtime surface: editor process, browser preview, Web build, or native. Use the [3.8 asset workflow](https://docs.cocos.com/creator/3.8/manual/zh/asset/asset-workflow.html), [dynamic loading](https://docs.cocos.com/creator/3.8/manual/zh/asset/dynamic-load-resources.html), [Asset Manager](https://docs.cocos.com/creator/3.8/manual/zh/asset/asset-manager.html), [Bundle](https://docs.cocos.com/creator/3.8/manual/zh/asset/bundle.html), and [release](https://docs.cocos.com/creator/3.8/manual/zh/asset/release-manager.html) manual pages for public behavior. For internals use the local [3.x study](../../../3.x/04-assets-and-loading.md).

1. Resolve the exact identity from `.meta`, including `主 UUID@子 ID` for imported subassets, and the scene/prefab `__uuid__`. Record API, Bundle, relative path, type, and subasset path. Confirm the requested path is exposed by that Bundle; a file under `assets/` is not automatically a `resources` path.
2. For loading failures, follow `bundle.ts::load/loadScene` → `asset-manager.ts::loadAny` → `preprocess.ts/config.ts/url-transformer.ts` → `pack-manager.ts/parser.ts/deserialize.ts` → `load.ts::loadDepends`. For a path with multiple matches, check the type; for redirects, check whether the destination Bundle is loaded. Check `replaceOverrideAsset` and `assetsOverrideMap` only when an override is configured. Distinguish `Asset.onLoaded` from `Component.onLoad`; `Bundle.loadScene` does not run the Scene.
3. For preload, trace `asset-manager.ts::preloadAny` through `fetchPipeline`, then require a separate load observation before claiming an initialized Asset exists.
4. For release, record UUID, `refCount`, `assets.has(uuid)`, scene `autoReleaseAssets`, static dependencies, dynamic ownership, persistent nodes, and `EDITOR`/`PREVIEW`/build conditions. Follow `asset.ts::addRef/decRef`, `release-manager.ts::{_autoRelease,tryRelease,_free}`, and `director.ts::runSceneImmediate`; include dependency injection, request increments, and `load.ts` → `clear(task,true)` decrements in the net reference count. `releaseAsset`, `Bundle.release`, and `releaseAll` force the target; `releaseUnusedAssets` does not. `removeBundle` only removes its configuration. `utilities.ts::cache` excludes SceneAsset and default assets.
5. For a live probe, establish that the target and its dependencies are not used by the active scene, then record cache/ref state across preload and load. Release only the test's own references. Treat the editor's `WeakCache` and non-editor `Cache` separately; recheck platform-specific behavior before generalizing to native.
6. For disk/import diagnosis, compare `.scene`/prefab `__uuid__` references with `dependUtil.getDeps` and `getDepsRecursively` in the same preview run; keep `主 UUID@子 ID` subassets distinct. Inspect the source and editor-generated `.meta` before the generated `library/` entry. The reproducible cold-load fixture is `3.8,7NewProject/assets/resources/stage4-probe.json` (UUID `f6a2d4ff-2327-4d1c-abe8-a8578a43d9fe`): confirm it is uncached before `resources.load('stage4-probe', JsonAsset)`, and release only a probe-owned reference.
   For a real scene-switch probe, confirm both scene names in the Bundle's `getSceneInfo`, then select an asset UUID in the old Scene's `dependUtil.getDeps` and absent from the new Scene's dependencies. Record `refCount`, `assets.has(uuid)`, and `isValid(asset,true)` before `director.loadScene`, in the launch callback, and after a delayed sample. In this workspace, `main.scene` → `stage4-empty.scene` makes `soldier.prefab` (`cfc53c4e-7956-482b-aebc-3fb1dcd36eef`) old-only; the [preview trace](../../traces/3.8.7-disk-scene-switch.jsonl) covers both `autoReleaseAssets` branches. Its `true` branch changed only the active disk Scene object in memory after a fresh reload; the source `.scene` remains `false`.
7. For a Mac native report, verify generated package contents, app startup, and visible scene separately from browser observations. The [native JSON trace](../../traces/3.8.7-mac-native-asset-lifecycle.jsonl) measures a cold `resources.load` callback, object-cache identity, net `refCount=0`, a probe-owned `addRef`, nonforced `releaseUnusedAssets`, and `decRef` followed by delayed invalidation. The [native disk-scene trace](../../traces/3.8.7-mac-native-disk-scene-switch.jsonl) measures `director.loadScene('stage4-empty')` with each `autoReleaseAssets` branch and the old-only Prefab. Reproduce by temporarily registering `Director.EVENT_AFTER_SCENE_LAUNCH` before `cc.game.run()` in generated Mac `application.js`; write logs through `jsb.fileUtils.writeStringToFile` under `jsb.fileUtils.getWritablePath()`. In this sandboxed build, writing to `/private/tmp` did not produce a log. Restore the generated script afterward. The traces cover this JSON, the Prefab fixture, and Mac process only; 350ms is a sampling wait, not a release guarantee. The `true` branch modifies the active old Scene in memory; the source `.scene` remains `false`.

Report the first failing or unexpected transition, matching source symbol, and evidence type: manual, static source, `.meta/scene` inspection, editor import, browser runtime, or native runtime. State when a needed surface is missing. The [measured 3.x preview cases](../../traces/3.8.7-asset-lifecycle.jsonl) cover a real Prefab, SceneAsset, isolated release-manager branches, and Director scene switches with in-memory scenes and assets; the separate [disk scene-switch trace](../../traces/3.8.7-disk-scene-switch.jsonl) covers `loadScene` with editor-created scenes. The [disk/import/Mac record](../../traces/3.8.7-disk-import-validation.jsonl) and [validation matrix](../../asset-validation-matrix.md) distinguish browser and native surfaces. When probing persistent nodes, inspect the new scene's `dependUtil._depends` entry: `_autoRelease` stores transferred `persistDeps` only when that record exists. A synthetic Scene without it does not reproduce a normally loaded scene. Consult the [stage 4 comparison](../../../comparisons/04-assets-and-loading.md) only after the 3.x path has its own evidence.
