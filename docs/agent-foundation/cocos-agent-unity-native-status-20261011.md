# CocosAgent 与 Unity 原生助手：当前状态和后续顺序

复核日期：2026-10-11。比较基线是 Unity Editor 内助手；Unity CLI/MCP/外部插件是可选互操作参考。

官方公开能力依据：[Assistant 的 Ask/Plan/Agent、上下文与权限](https://unity.com/blog/unity-ai-assistant-ask-plan-agent-mode-explained)、[Unity AI 工具入口](https://unity.com/features/ai)。这是产品行为参考，不据此推断 Unity 内部进程、事务或实现，也不将外部插件的 skills 等同于原生助手内的同一分发机制。

## 已有能力与缺口

| 方向 | CocosAgent 已有 | 实际缺口 |
| --- | --- | --- |
| Creator 内入口 | 扩展面板，Creator 管理 sidecar/MCP；DeepSeek 接入；原生 Ask 实测；LinkUpClient 磁盘包已升至 extension 0.3.4 / MCP 0.3.3，并保留 0.3.1 与 0.3.3 回滚副本 | Creator 尚未重载新包；独立工程的面板直发和升级后的运行态仍需验收；Node 20+ 是本机依赖 |
| 实时项目上下文 | 实例/版本/能力、活动场景、节点/组件、PNG 查询；面板选择展示；新包逐回合传递有界选择上下文；Agent 写入前强制读取并校验当前 `AGENTS.md` 哈希 | 非空选择同步、项目约定实际消费及更广的上下文检索尚未实机验收 |
| 任务知识 | 12 个产品 skill 的目录、正文、声明引用及版本/哈希核对；真实模型读取有证据 | 各任务的原生面板 skill 使用尚未逐项通过；数量不代表能力完成 |
| 计划与权限 | Ask/Plan/Agent 模式、计划卡和步骤执行、写入审批 | 计划编辑与分级会话权限不完整；指定 PNG 的整条原生面板写入仍未通过 |
| 场景/资源制作 | 节点、Sprite 引用、PNG 管线、Prefab、Bundle、构建、补偿/重放等底层实测 | 底层 Host/MCP 证据不等于原生模型已完成这些任务；合同白名单限制仍存在 |
| 脚本开发 | 现有 JS 读取、差异计划、受约束补丁、编译和恢复；原生面板写入/对账/补偿已验，外部 CUA 实际点击计数与恢复后行为已验 | 新 ID 原生重放和真实错误修复未验；Plan 非 JSON、调度需精确提示的缺口仍在；无通用新脚本/多文件开发闭环 |
| 观察运行 | 特定内容预览、运行时回执、压力探针和历史视觉证据 | 普通项目 Console、运行状态、截图尚未形成 Agent 可调用的通用闭环 |
| 连续任务 | 会话/计划的工程隔离用户目录存储、conversation ID、取消/差异/恢复入口有自动测试；LinkUpClient 扩展已升级到磁盘 0.3.4 | Creator 重载后的恢复、真实取消与多轮选择/约定验证仍待实机验收 |

凭据已放 OS 用户目录而非项目资产；目前仍是权限受限明文文件，不是系统密钥链。恢复以严格身份、原操作账本、磁盘/编辑器对账为准，不宣称比 Unity 更优；两者没有同条件实测比较。

## 下一步

1. 收完指定现有 PNG 的原生面板计划、批准、挂接、保存读回、重开、预览、补偿与重放。
2. 收完已有按钮的脚本任务：真实写入和编译，再实际点击验证；失败按原记录恢复。
3. 补普通预览、Console、运行状态与截图，先发现并修复上述任务的运行错误。
4. 完成会话/计划持久化、取消、差异与恢复入口，再测同一项目多轮任务。
5. 随任务补齐独立工程面板、项目约定、选择同步和升级验收，以真实 LinkUpClient 使用为依据。
6. 按真实项目阻塞扩充命令和 skill，建立可重复任务回归；资源/性能/源码改造由具体问题触发。

当前只推进 Creator 2.4.15；3.x、广泛资源生成器、外部适配扩张及无测量依据的引擎重构不列近期门槛。招聘目标通过实际案例覆盖编辑器自动化、资源管线、运行时验证与工程恢复；源码优化沿用测量先行。
