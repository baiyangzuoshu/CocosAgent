## 优先复测顺序

1. **P0：建立可复现运行入口。** 分别记录 Creator 版本、示例路径、预览 URL、Web/原生、场景名、引擎来源（是否配置相邻源码构建）；页面必须可见，游戏未暂停。预览服务未可访问时，保留端口/编辑器状态，不写行为结论。临时注入生成脚本时须先记 SHA-256，完成后恢复并核对；源场景不作探针改动。
2. **P0：补音频剩余平台与竞态。** 两版 A/B Clip 的 Web 加载、并发、普通组件结束/停用/销毁、动态 Clip 跨磁盘场景与显式释放已有局部轨迹；3.8 静态场景 Clip 的引用计数和自动释放也已验证。2.4 在内存构造 Scene 依赖后，也验证了给定依赖表时的自动释放分支；它不是正式导入场景的证据。3.8 WebAudio one-shot 跨场景自然结束、达限淘汰和成功慢加载期间源节点销毁均已用底层调用打点。下一步先让 2.4 AssetDB 重新导入静态场景，再对其运行独立分支；原生/DOM Audio、后台中断与请求失败竞态仍需分别建最小实验。one-shot 无公开停止/状态句柄，不能仅凭普通组件状态断言它是否被淘汰。
3. **P0：补剩余粒子画面。** 两版 2D 的零粒子/发射中 × 自动移除四组自然帧和同步截图已完成，见上表；下一轮专测 3.8 停发射后主动使 UIRenderer 变脏、无 `renderData` 早退与导入资产。两版 3D 已有自然 Director 帧，3.8 临时 CPU 粒子画面已确认；2.4 活动期截图仍未见粒子，需隔离相机、材质和渲染链。3.8 RenderCulling 的 Pause、PauseAndCatchup、AlwaysSimulate 单列，不从关闭剔除的状态探针外推。
4. **P0：补其他接触条件与平台。** 两版 2D Box2D 的自然帧 Begin 与移动刚体回写已有各自 Web 轨迹；初始重叠传感器的 Begin 不足以覆盖后续碰撞时节点和 Body 的位置差。3.8 同时启用 2D 和 3D 时，两系统各发一组同名全局 Physics 标记，诊断时要标明来源。监听重建对照见[2.4 探针](probes/stage9-2d-contact-registration-2.4.js)与[3.8 探针](probes/stage9-2d-contact-registration-3.8.js)；两版监听重建分别有[2.4 关闭/启用轨迹](traces/2.4.15-stage9-2d-listener-reenable-headless-web.jsonl)与[3.8 `apply()` 轨迹](traces/3.8.7-stage9-2d-listener-apply-headless-web.jsonl)；其他后端和原生仍待运行验证。
5. **P1：补 Builtin 与其他 3D 后端。** 当前 2.4 Cannon、3.8 Bullet 的同形状射线和四组自然帧事件已有 Web 轨迹；Kinematic/Static 非 trigger 对分别归为 trigger 与 collision，不能跨后端套用。Builtin 另用[2.4](probes/stage9-3d-builtin-events-2.4.js)/[3.8](probes/stage9-3d-builtin-events-3.8.js)专用探针，必须先确认实际 World 为 `BuiltinWorld`，比较 collider-collider、trigger-collider、trigger-trigger。3.8 Cannon/PhysX 及原生需独立配置与记录；未启用者只保留源码结论。3.8 sweep 只在实际 Bullet/PhysX 可用时测，不能把 `false` 一概写成“无命中”。

每份新 JSONL 至少记录 `version`、`creatorVersion`、`environment`、`scene`、`engineProvenance`、`backend`、`probe`、`phase`、时间戳、输入条件与原始返回值。探针异常也记录，不能归入“行为通过”。运行后同步更新两版独立笔记、[阶段 8 比较](../comparisons/08-animation-and-effects.md)、[阶段 9 比较](../comparisons/09-physics-and-spatial.md)及相应版本专属 skill；只将实测条件下的结论升级为运行规则。
