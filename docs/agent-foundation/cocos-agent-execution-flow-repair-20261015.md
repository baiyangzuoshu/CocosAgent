## 合同和兼容行为

1. Plan 仍为 version 2；write 的 targets 现在是必填。旧 v1 或缺少 targets 的 v2 write 计划显示需要重新生成，已有操作先核对原账本。计划生成提示、解析器、Host、TS、任务持久化、面板和产品 skill 同步。
2. 每项目恢复存储带 revision/CAS、原子替换和工程身份检查，不随 24 条最近运行记录被丢弃。启动时仅从仍可读取的旧会话迁移未决操作；已经被历史版本裁剪的记录无法凭空恢复。多个已知未决操作逐个处理；无法验证身份的旧记录保持阻塞，不猜测其他 ID。
3. 已有语义写入在审批前补齐 operationId。实际写入只能在持久化意图成功后分发；已明确无副作用的拒绝可清理该意图，丢失响应或身份矛盾保留。Agent 恢复工具与面板精确核对均可在明确结果后解锁；当前任务未结束时，面板不并发核对历史操作。操作仍需 preview/runtime 时，只解除副作用不确定性，不替代验收。
4. 自由 Agent 对部分明确的节点位置语句作确定性绑定；其他内容写入必须用有可审阅目标的 Plan 才能通过最终目标验收。此实现没有宣称完整理解任意自然语言目标。复杂脚本行为仍受缺少原生交互断言的限制。
5. 临时 apply 后补偿保留两次操作证据；最终读取必须在最后写入之后。恢复步骤以其目标或原操作 before-state 验收，中间值不替代最终值。
6. 本轮修复仅覆盖 Creator 原生 Host 管理的 Agent 分发；直接外部 MCP/JSONL 调用不因此自动获得同样的跨 run Host 状态管理。
