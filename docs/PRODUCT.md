# 产品定义与范围

## 产品定义

> CocosAgent 是一个本地优先、权限受控、能够感知 Cocos Creator 项目并操作编辑器的游戏开发
> Agent。

其构成可以表示为：

```text
CocosAgent
= 模型推理
+ Cocos 项目上下文
+ Creator 编辑器与构建工具
+ 开发者协作界面
```

## 目标用户

- 使用 Cocos Creator 2.4.15 维护现有项目的客户端开发者。
- 需要快速理解遗留场景、Prefab 和组件关系的维护者。
- 希望自动完成重复性 UI、节点、脚本和资源操作的小型团队。
- 需要在明确权限和变更预览下使用 AI 编码能力的项目负责人。

## 核心场景

1. 项目理解：识别 Creator 版本、资源目录、场景、Prefab、脚本和组件关系。
2. 脚本开发：创建或修改 TypeScript/JavaScript 组件并检查编译结果。
3. 场景操作：查询节点树，创建节点，挂载组件，修改安全属性并保存。
4. Prefab 操作：读取 Prefab 结构，通过编辑器创建或更新 Prefab。
5. 资源管理：导入图片、音频等资源，等待 AssetDB 刷新并获取 UUID。
6. 运行验证：启动预览、采集 Creator 控制台日志、报告错误。
7. 构建辅助：配置并触发 Web 或目标平台构建，返回产物与摘要。

## MVP 范围

MVP 必须实现：

- 识别合法的 Creator 2.4.15 项目。
- 生成有界的项目摘要和资源索引。
- 安全读写普通脚本与配置。
- 连接安装在项目 `packages/` 中的 Creator Bridge。
- 读取当前场景、节点和组件摘要。
- 创建节点、挂载组件、修改白名单属性并保存场景。
- 获取编辑器日志并执行 Web Preview/Build 验证。
- 对写操作进行审批、备份、审计和失败回滚。

## 非目标

首期不支持：

- Cocos Creator 3.x。
- 任意重写 `.fire`、`.prefab` 或 `.meta` 序列化文件。
- 自动修改 `engine2.4.15/`。
- 深度编辑 Android Studio 或 Xcode 工程。
- 自动发布应用商店。
- 未经确认批量删除资源或节点。
- 将 Creator Bridge 暴露到局域网或互联网。

## 成功指标

- 测试项目识别成功率为 100%。
- 场景读取不改变项目文件。
- 支持的节点操作在 Creator 重启后仍能正确加载。
- 每次写操作都有变更摘要、审批记录和验证结果。
- 失败操作不会留下损坏的 Scene、Prefab 或 Meta。
- MVP 示例任务可以在测试项目中重复执行并自动验收。
