# Claude Code Game Studios 课程大纲

## 课程目标

以 `engine/Claude-Code-Game-Studios/` 中的 CCGS 1.2.0 快照为依据，沿项目入口、Agent、Skill、配置、自动化和质量系统逐层阅读，建立对该模板实际边界的理解。

## 阅读约定

- 规划 20 课，编号 `s00` 至 `s19`；完成的课件按编号放在 `sNN_主题/README.md`。
- 每课按“问题 → 源码位置 → 观察步骤 → 结果 → 简化边界”组织，沿用 `learn_3.8cocoscreator` 的教学骨架。
- 目前编写了第 0–16 课，第 16 课是当前学习内容；第 17–19 课是路线规划，尚未展开成课件或实践文件。
- CCGS 是 Claude Code 工作流模板，不是游戏引擎。本课程不重写 Agent/Skill 来模拟它；实践环境会复制源码快照到隔离工作区，再调用真实 Skill、Hook 和辅助脚本。
- 结论优先由本地快照中的配置、脚本、合同和文档交叉核对；README 的概述不能单独证明运行行为。
- 课程针对当前本地快照；版本更新后应重新核对路径和行为。

## 阶段划分

1. **入口与协作基础（0–3）**：知道模板由什么组成，以及工作如何分工。
2. **Skill 与项目控制（4–8）**：理解任务指令、合同、配置和决策方式。
3. **自动约束与引擎知识（9–11）**：看清事件自动化、路径提示和版本资料。
4. **游戏开发工作流（12–16）**：跟踪入门、设计到架构、Story、Gate 和 QA。
5. **维护工作室框架（17–19）**：测试、定制和升级这套模板。

课程入口见 [README](README.md)。
