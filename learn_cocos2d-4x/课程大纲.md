# Cocos2d-x 4.0 源码学习大纲

## 课程目标

以本地 `engine/cocos2d-x-4/` 的 C++ 源码为准，逐课实现容易运行和阅读的精简版本。代码按引擎职责分层，并标注对应源码位置；不把本地静态研究结果描述成运行时验收。

本目录只放 4.0 版本的独立代码。历史版本课程分别见 [Cocos2d-x 1.x](../learn_cocos2d-1x/README.md)、[2.x](../learn_cocos2d-2x/README.md) 和 [3.x](../learn_cocos2d-3x/README.md)。

## 实现约定

- 每课放入独立的 `sNN_主题/` 目录，保存完整代码快照。
- 目录结构尽量镜像 Cocos2d-x 源码，例如 `src/cocos/2d/CCNode.cpp` 对应 `engine/cocos2d-x-4/cocos/2d/CCNode.cpp`。
- 每课只增加一个主要概念，删去渲染、平台和服务模块等无关部分；课程 README 写明简化内容。
- 同主题课在不同引擎课程中互相链接，方便并排阅读；课程实现分别维护。
