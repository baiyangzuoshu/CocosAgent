# Claude Code 源码学习大纲

## 课程目标

以 `engine/claude-code-analysis-main/src/` 为静态源码依据，理解 CLI 如何启动会话、准备上下文、请求模型、执行受权限约束的工具，并把结果写回界面和会话。首轮聚焦交互主链；MCP、插件、Skills、子 Agent 等作为后续扩展主题。

## 阅读约定

- 本课程分析生产代码，不重建完整 CLI，也不把各课描述为可独立运行的代码快照。
- 每课先说明问题，再给源码文件和符号、关键调用或状态流、可核对的观察结果及范围边界。
- 源码路径相对于仓库根目录；路径和符号是阅读入口，不代表只需阅读这些行。
- 当前源码目录没有 `package.json` 等构建入口，结论属于静态源码证据；不外推为目标运行时行为。

## 课程终点

完成后应能独立解释交互会话的主链：CLI 入口选择模式，REPL 组装消息和上下文，Query 驱动模型流，工具调用经过权限和执行编排，结果进入会话并可能触发下一轮请求。扩展、远程会话和 Print/SDK 路径作为主链之外的分支理解。
