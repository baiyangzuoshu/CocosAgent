# learn-dsh 课程总纲

## 课程目标

通过 30 个逐步增加机制的独立示例，复刻 DeepSeek Harness 的主要运行路径：插件组合、应用启动、Agent 与 Session、模型和工具调用，以及代表性的扩展和应用入口。

## 学习约定

- 每课放在独立的 `sNN_主题/` 目录，包含完整、可单独运行的代码快照。
- 教学实现使用 TypeScript + Deno，不依赖 `deepseek-harness` 的构建产物；目标仓库只作为源码对照。
- 核心 Agent 课程使用确定性的 Fake LLM，不要求 API Key；接触执行能力时采用受限示例。
- 每课列出目标仓库的源码入口、可观察结果和简化点。Harness 的实现变化时，以当前工作区代码为准。
- 扩展课各选一个代表性机制；相关包放入源码地图，不逐包复刻。
