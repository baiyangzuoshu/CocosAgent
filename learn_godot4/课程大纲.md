# learn_godot4 课程大纲

## 课程目标

以仓库本地 `engine/godot-4.7/` 源码为依据，学习 Godot 4.7.3-rc 的启动、对象系统、场景树、资源、输入、渲染、物理、动画、音频及编辑器架构。每课追踪 C++ 源码，并用最小 Godot/GDScript 项目观察运行时行为。

课程组织参考 `learn_3.8cocoscreator/` 的独立课次和源码对照方式；不复用 Creator 的实现模型或强行套用相同 API。Godot 1.1、2.1、3.6 各有独立课程，跨版本结论只在对应课程明确对照时给出。

## 实现约定

- 每课放在独立的 `sNN_主题/` 目录，尽量按源码职责组织实验文件。
- 每课是一份可单独打开和运行的最小 Godot 项目，不依赖前课的项目状态。
- GDScript 实验用于观察 Godot 的公开行为；C++ 源码作为实现依据，不在实验中仿写引擎内部机制。
- 每课记录问题、源码文件与关键函数、实验入口、可观察结果、简化点、运行命令和验证环境。
- 静态源码、Godot 项目运行、编辑器交互、构建及目标平台结果分别记录；未验证的证据不作推断。
- `engine/godot-4.7/` 是只读上游源码快照，不作为课程代码修改目标。
- 运行前确认本机 Godot 工具版本和目标平台；下载依赖、安装工具或构建引擎前先核对工具链并取得授权。
- 不提交 `.godot/`、构建输出及其他缓存产物。

## 证据边界

课内的 C++ 调用链说明源码职责；GDScript 项目只用于观察该快照对应的引擎行为。只有实际运行过的编辑器版本、运行时和平台才记录为运行验证。源码阅读、实验运行和 Godot 引擎构建分开报告。
