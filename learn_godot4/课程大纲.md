# learn_godot4 课程大纲

## 课程目标

以仓库本地 `engine/godot-4.7/`（`4.7.3-rc`）为依据，沿 C++ 源码追踪 Godot 启动、帧循环、对象类型、Variant 和脚本调用。S00–S20 每课配有独立的最小 Godot/GDScript 项目，用来观察对应版本公开行为。

本代边界：使用 project.godot、ClassDB、RefCounted、RenderingServer、Callable 与 Signal。

## 课次结构

- 每课先提出一个可由源码回答的问题，列出关键函数、参数/状态传递和调用顺序。
- `src/upstream/` 收录对应快照的关键 C++ 原文行段，摘录文件标注原始路径与行号；完整上下文仍在只读 `engine/` 快照中。
- 每课项目独立可打开；GDScript 只验证脚本可观察的行为，不仿写 C++ 内部机制。
- README 将静态源码结论、预期输出、实际运行记录和简化边界分开；没有运行记录时不声称已验证。

## 证据边界

课内的 C++ 调用链说明源码职责；GDScript 项目只用于观察该快照对应的引擎行为。只有实际运行过的编辑器版本、运行时和平台才记录为运行验证。源码阅读、实验运行和 Godot 引擎构建分开报告。
